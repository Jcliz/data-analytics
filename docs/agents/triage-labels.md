# Rótulos de triagem

As skills falam em cinco papéis de triagem. Esta tabela liga cada papel ao rótulo usado nas issues deste repositório.

| Rótulo nas skills (mattpocock/skills) | Rótulo neste repositório | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | O grupo precisa avaliar a issue |
| `needs-info` | `needs-info` | Falta informação de quem abriu |
| `ready-for-agent` | `ready-for-agent` | Bem especificada, pronta para um agente de IA executar |
| `ready-for-human` | `ready-for-human` | Precisa de uma pessoa (decisão do grupo, gravação, envio no Canvas) |
| `wontfix` | `wontfix` | Não será feita |

Quando uma skill citar um papel (por exemplo, "aplique o rótulo de pronta para agente"), use o rótulo correspondente da tabela.

Os demais rótulos do repositório (entrega, área, destino e `pendencia-cruzada`) estão no [plano de tarefas](../../entregas/plano-de-tarefas.md), seção 4.
