# RA3 — Analysis, Visualization and Machine Learning

> Transcrição da tarefa do Canvas (10 pontos, tentativas ilimitadas, prazo 18/11/2026), lida em 05/11/2026. O envio é uma **URL** ("Insira o URL da web") e conta para todo o grupo PjBL. A tabela de pontuação ("rubrica da atividade") não veio no PDF da tarefa; quando o grupo a tiver, ela entra na seção 6.

## 1. Objetivo

O objetivo do RA3 é concluir o projeto de Data Analytics, utilizando os dados preparados e processados nas etapas anteriores para produzir análises estatísticas, visualizações e interpretações que contribuam para responder ao problema definido pela equipe.

Nesta etapa, os estudantes também deverão explorar uma aplicação simples de Machine Learning, utilizando técnicas de classificação ou regressão para investigar uma possibilidade de previsão a partir dos dados.

O foco da avaliação está na adequação das técnicas escolhidas, na interpretação dos resultados e na capacidade de transformar dados em informações relevantes, e não na complexidade das implementações.

## 2. Requisitos

### 2.1 Análise estatística descritiva

Realizar uma análise estatística dos dados, contemplando:

- **Tendência central:** utilização de média e/ou mediana para compreender valores representativos.
- **Dispersão:** utilização de medidas como amplitude ou desvio-padrão para analisar a variabilidade.
- **Distribuição:** investigação da frequência, concentração ou distribuição dos valores.

As medidas utilizadas devem ser coerentes com as características dos dados e com o problema investigado.

A equipe deverá apresentar os resultados e explicar o que eles representam no contexto do projeto.

### 2.2 Visualização e interpretação dos dados

Produzir pelo menos três visualizações que contribuam para compreender diferentes características dos dados.

As visualizações deverão:

- Ser adequadas às informações apresentadas.
- Possuir identificação clara das variáveis e dos resultados.
- Ser acompanhadas de uma breve interpretação.

A equipe deverá identificar padrões, tendências, diferenças ou comportamentos relevantes, evitando limitar a análise à simples apresentação de gráficos.

### 2.3 Amostragem e representatividade

Apresentar uma breve análise sobre a representatividade dos dados utilizados, abordando:

- A origem e a abrangência do conjunto de dados.
- Se os registros representam adequadamente o problema investigado.
- Possíveis limitações ou vieses que possam influenciar os resultados.

Não é obrigatório implementar um procedimento de amostragem. Caso a equipe utilize uma amostra, deverá explicar como os registros foram selecionados.

### 2.4 Aplicação de Machine Learning

Implementar uma aplicação simples de aprendizagem supervisionada, escolhendo uma das abordagens:

- **Classificação:** prever uma categoria ou classe.
- **Regressão:** estimar um valor numérico.

A implementação deverá contemplar:

1. Definição do problema preditivo.
2. Identificação da variável-alvo (*target*) e das características utilizadas (*features*).
3. Separação dos dados para treinamento e teste.
4. Treinamento de um modelo e realização de previsões.
5. Avaliação dos resultados utilizando pelo menos uma métrica adequada ao problema.

A equipe poderá utilizar qualquer algoritmo ou ferramenta que atenda aos objetivos da atividade. Não é obrigatório utilizar KNN, regressão linear ou scikit-learn.

**Importante:** caso o conjunto de dados original não possua características adequadas para uma aplicação supervisionada, a equipe poderá utilizar outro conjunto de dados exclusivamente para esta etapa, justificando brevemente a escolha.

### 2.5 Conclusões

Apresentar uma conclusão geral do RA3, contemplando:

- Principais resultados identificados nas análises estatísticas e nas visualizações.
- Interpretação do desempenho do modelo de Machine Learning.
- Limitações dos dados e das análises realizadas.
- Relação dos resultados com o problema definido no projeto.

## 3. Entrega

A equipe deverá entregar o repositório do projeto contendo:

1. **Implementação:** código-fonte ou notebook com as análises estatísticas, visualizações e aplicação de Machine Learning.
2. **Documentação:** descrição das técnicas utilizadas, resultados obtidos e respectivas interpretações.
3. **Instruções de execução:** informações necessárias para executar e verificar as implementações.

As análises poderão ser incorporadas ao projeto existente ou organizadas em arquivos específicos para o RA3.

Não há obrigatoriedade de ferramenta ou biblioteca específica. São aceitas diferentes tecnologias, desde que permitam demonstrar os requisitos e verificar os resultados.

As implementações deverão estar funcionais e acessíveis para avaliação.

## 4. Avaliação somativa

**Data:** 18/11/2026.

A avaliação considerará o atendimento aos requisitos, a coerência das análises, a qualidade das interpretações e a compreensão demonstrada pelos integrantes.
